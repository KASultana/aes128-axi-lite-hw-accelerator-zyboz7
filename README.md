# AES-128 Key Encryption Hardware Accelerator (AXI-Lite) — ZYBO Z7 (Zynq-7000)

This project implements an **AES-128 hardware encryption accelerator** in **VHDL (RTL level)** and integrates it with the Zynq Processing System using an **AXI4-Lite** interface. A **Vitis bare-metal C application** benchmarks **hardware vs software AES** execution time and reports speedup.

Presentation slides are included in `docs/SoC_Presentation.pdf`.

## Objective
- Design and implement an AES-128 hardware encryption accelerator
- Develop AES core using VHDL at RTL level
- Integrate the accelerator using AXI-Lite interface
- Perform hardware–software co-design using Vivado and Vitis
- Compare software vs hardware AES performance and demonstrate speedup

## Hardware & Software Platform
- **FPGA Board:** ZYBO Z7 (Zynq-7000 SoC)
- **Hardware Design Tool:** Xilinx Vivado **2019.2**
- **Software Development Tool:** Xilinx Vitis
- **HDL:** VHDL
- **Interface Protocol:** AXI-Lite

## Repository Overview
- `hardware/rtl/`
  - `aes128key.vhd` — AES-128 encryption core
  - `myip_12_v1_0_S00_AXI.vhd` — AXI4-Lite wrapper (register interface + load/ready control)
- `hardware/tb/`
  - `aes128keyTB.vhd` — testbench (FIPS-197 test vector)
- `software/vitis/aes_hw_sw_timing/src/main.c`
  - Writes plaintext to AXI-Lite registers, triggers HW encryption, polls ready, reads cipher
  - Runs software AES (ECB) as reference and reports timing + speedup

## Register Map (AXI-Lite)
Base address is generated by Vivado and exposed in Vitis via:
`XPAR_MYIP_12_0_S00_AXI_BASEADDR`

| Offset | Name | Access | Description |
|---:|---|---|---|
| 0x00 | P0 | W/R | W: plaintext[127:96], R: cipher[127:96] |
| 0x04 | P1 | W/R | W: plaintext[95:64],  R: cipher[95:64] |
| 0x08 | P2 | W/R | W: plaintext[63:32],  R: cipher[63:32] |
| 0x0C | P3 | W/R | W: plaintext[31:0],   R: cipher[31:0] |
| 0x10 | CTRL | W/R | bit0: write `1` = start(load pulse), read bit0 = ready (latched) |

See `docs/register_map.md` for details.

## How it works (High level)
1. **RTL Design & Verification**
   - AES core implemented in VHDL and verified with testbench (FIPS-197 vector)
2. **AXI-Lite Integration**
   - Custom AXI-Lite wrapper provides memory-mapped registers
3. **Hardware Implementation**
   - Synthesis/implementation in Vivado; bitstream + XSA exported
4. **Software Development**
   - Vitis imports the hardware platform and runs a bare-metal C test
5. **Performance Evaluation**
   - Execution time measured for both HW and SW; speedup reported

## Build & Run (Suggested flow)
### A) Vivado 2019.2
1. Open Vivado 2019.2
2. Create a block design:
   - Zynq7 Processing System
   - Your custom AXI-Lite IP (`myip_12`)
   - Connect AXI-Lite to PS (M_AXI_GP)
3. Generate bitstream
4. Export hardware platform (XSA)

> Tip: Prefer committing **TCL scripts** under `hardware/vivado/scripts/` to recreate the project.

### B) Vitis
1. Create a platform from exported XSA
2. Create a bare-metal application project
3. Add `main.c` and the AES software library (`aes.c/.h`)
4. Build and run on ZYBO Z7
5. Open Serial Terminal to see output

## Notes / Known behavior
- The `ready` status in CTRL is latched (stays `1` until reset).  
  If you want “per-operation ready”, clear the latched flag when `start` is written.
